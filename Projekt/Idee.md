# Projekt Idee

Eine Multi-Container Chat Plattform gehostet mit Kubernetes. Die Plattform besteht aus der Chat Applikation Rocket.Chat, die im Hintergrund auf einem Postgres Cluster Daten speichert. Dazu gehört ein Monitoring, welches die Services überwacht.

Eine Multi-Container E-Commerce Plattform gehostet mit Kubernetes. Saelor ist die Hauptplattform, die aus einem Front- und Backend Image besteht.
